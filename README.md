# MiMo AI — Тестовый сайт

Динамический сайт на Python Flask, созданный с помощью AI-ассистента MiMo.

**Сайт вживую:** https://site-invweb.fly.dev/

## Описание

Сайт демонстрирует возможности AI-помощника в разработке. Включает два основных раздела с подробной информацией об аниме.

## Разделы сайта

### Главная страница (`/`)
- Приветствие и навигация по разделам

### About (`/about`)
- Информация о проекте MiMo AI
- Описание того, как ИИ помогает программистам

### Гайвер (`/guyver`)
Раздел, посвящённый аниме-франшизе «Гайвер» (Guyver) — персонажу манги, аниме и фильмов Ёсики Такая.

#### Подразделы:

**Хронология** (`/guyver/chronology`)
- Интерактивная лента: манга → OVA → сериал → фильмы
- Фильтрация по типу (манга, OVA, аниме, фильмы)
- Рекомендации «с чего начать» для начинающих и фанатов

**Сравнение версий** (`/guyver/comparison`)
- Таблица сравнения: манга vs аниме 2005 vs фильмы 1991/1994
- 9 аспектов: Сё/Шон, «Кронос», отец, второй Гайвер, зоалорды, Создатели, финал, тон, рекомендация

**Карта лора** (`/guyver/lore`)
- Визуальная карта связей: Создатели → Зоафорт → «Кронос» → Зоаноиды → Гайвер
- Иерархия сил с цветовой кодировкой
- Ключевые связи между элементами вселенной

**Галерея трансформаций** (`/guyver/gallery`)
- 9 форм брони: базовые, усиленные, финальные
- Фильтрация по стадии
- Шкала мощности: базовая → усиленная → финальная

**Какой ты зоаноид?** (`/guyver/quiz`)
- Квиз из 7 вопросов
- 4 результата: Грегель, Доргу, Тигранос, Бṝозон
- Описание способностей и роли каждого зоаноида

**Где смотреть** (`/guyver/legal`)
- Платформы по странам: Япония, Россия/СНГ, США/Европа
- Форматы: манга, аниме, фильмы, OVA
- Таблица цен по странам и форматам

### Мой сосед Тоторо (`/totoro`)
Раздел, посвящённый аниме-фильму Studio Ghibli «Мой сосед Тоторо» (1988).

- **Обзор**: жанр, студия, режиссёр, композитор, премьера, длительность
- **Сюжет**: полное описание истории о девочках и лесном духе
- **Персонажи**: 8 карточек (Тоторо, Сацуки, Мэй, Тацуо, Ясуко, Канта, Котобус, Сусуватари)
- **О Тоторо**: три вида (О, Тю, Тиби) с описаниями
- **Интересные факты**: 8 фактов (астероид, вид перипатуса, движение «Дом Тоторо»)
- **Саундтрек**: Дзё Хисаиси
- **Прокат и награды**: премии Animage и «Кинэма Дзюмпо»
- **Где посмотреть**: Crunchyroll, Disney+, Amazon, Blu-ray
- **Связь с другими фильмами Гибли**

## Технологии

- **Backend**: Python 3.12, Flask
- **Frontend**: HTML5, CSS3, vanilla JavaScript
- **Деплой**: Fly.io (Docker)
- **Контроль версий**: Git + GitHub

## Структура проекта

```
site/
├── app.py                    # Flask-приложение
├── requirements.txt          # Зависимости (flask, gunicorn)
├── runtime.txt               # Версия Python
├── Procfile                  # Конфигурация для Render
├── Dockerfile                # Docker-образ для Fly.io
├── fly.toml                  # Конфигурация Fly.io
├── .gitignore
├── static/
│   ├── style.css             # Все стили сайта
│   ├── guyver.jpg            # Картинка Гайвера
│   └── totoro_main.svg       # SVG-иллюстрация Тоторо
└── templates/
    ├── index.html            # Главная
    ├── about.html            # О проекте
    ├── guyver.html           # Хаб Гайвера
    ├── guyver_chronology.html
    ├── guyver_comparison.html
    ├── guyver_lore.html
    ├── guyver_gallery.html
    ├── guyver_quiz.html
    ├── guyver_legal.html
    └── totoro.html
```

## Запуск локально

```bash
cd ~/Projects/site
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python app.py
```

Откроется на `http://127.0.0.1:3000`

## Деплой

```bash
fly deploy --yes
```

Публичный сайт: https://site-invweb.fly.dev/
